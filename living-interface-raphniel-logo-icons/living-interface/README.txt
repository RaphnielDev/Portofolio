LIVING INTERFACE — Raphniel Portfolio

Cara menjalankan:
1. Ekstrak folder living-interface.
2. Buka folder di VS Code.
3. Buka index.html langsung di browser, atau gunakan ekstensi Live Server.
4. Semua halaman memakai style.css dan script.js yang sama. Jangan pindahkan file gambar dari folder assets.

Halaman: index.html, about.html, projects.html, services.html, skills.html, contact.html.

Catatan: statistik tidak memakai klaim jumlah klien palsu. Foto profil dan gambar proyek diambil dari aset yang diberikan. Tautan proyek demo belum ditambahkan karena URL publik belum tersedia.
